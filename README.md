# Snipex Personal Command Center

Mobile-first personal dashboard for links, PC specs, academics, tasks, DigiGold placeholder data and VoidReign.

## Stack
HTML5 + CSS3 + vanilla JavaScript modules, localStorage, GitHub and Vercel.

## Structure
```
COMMAND-CENTER/
├── public/favicon.svg
├── src/app.js
├── src/data.js
├── src/style.css
├── index.html
├── vercel.json
└── README.md
```

Connect this repository to Vercel for automatic deployments. Keep private account credentials out of frontend code.
